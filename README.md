# Shon Johnson II — Athlete Site

This is a static first-pass homepage for shonjohnson.com.

## Preview locally
Open `index.html` in a browser.

For best results, run a tiny local web server from this folder:
- Python: `python -m http.server 8080`
- Then visit `http://localhost:8080`

## What to edit next
- Replace placeholder `#` links with Hudl / YouTube / game links.
- Add a real lacrosse image when available.
- Update stats/profile details as desired.
- Add separate pages for highlights, games, photos, and journal.

## Recommended deployment
Cloudflare Pages, Netlify, or Vercel. Point `shonjohnson.com` to the deployed project.
